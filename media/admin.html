Admin belépés

GitHub személyes hozzáférési token szükséges.

Fine-grained token létrehozásakor csak a pteszgy-new repositoryt válaszd ki, és adj Contents: Read and write jogosultságot. Állíts be lejárati időt. A token csak ebben a böngészőlapban marad, kilépéskor törlődik. Token létrehozása a GitHubon ↗
